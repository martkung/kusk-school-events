# KUSK Events

เว็บแอปกิจกรรมของโรงเรียน สำหรับสมัครเข้าร่วม ดูสถานะ เปิดบัตร QR เช็คอิน และจัดทำรายงาน

## ความสามารถ

- เข้าสู่ระบบด้วย Google หรือ LINE และเก็บข้อมูลชื่อ–นามสกุลกับเบอร์โทร
- แสดงกิจกรรมพร้อมโปสเตอร์ รายละเอียด และ QR สำหรับแชร์กิจกรรม
- จัดการกิจกรรม เจ้าหน้าที่รายกิจกรรม การอนุมัติ และถังขยะ
- เช็คอินด้วย QR บนมือถือ พร้อมลายเซ็นและรายงาน
- แบนเนอร์ประชาสัมพันธ์และการอัปเดตข้อมูลแบบ realtime

## โครงสร้าง

- `dist/` — ไฟล์เว็บไซต์ปัจจุบัน
- `functions/` — Firebase Cloud Functions และการตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์
- `firebase/` — Rules การตั้งค่า และเครื่องมือดูแลระบบ
- `*.test.mjs` — การทดสอบด้วยข้อมูลจำลอง
- `presentation-assets/` — ภาพประกอบสำหรับสาธิต
- `legacy-prototype/` — ต้นแบบเก่า ไม่ใช่เว็บไซต์ปัจจุบัน

## เปิดในเครื่อง

ใช้ Node.js 22 จากโฟลเดอร์นี้:

```sh
node server.cjs
```

เปิด http://127.0.0.1:5180 เว็บไซต์ใช้ Firebase ตามค่าที่ตั้งไว้ใน `dist/firebase-client.js` การเปิดในเครื่องไม่ได้แยกฐานข้อมูลให้โดยอัตโนมัติ ควรใช้ Firebase สำหรับทดสอบก่อนทดลองเขียนข้อมูล

## ทดสอบ

```sh
node --test *.test.mjs
```

ชุดทดสอบใช้ข้อมูลจำลอง ไม่ได้ยืนยันการทำงานบนมือถือจริงหรือแทนการทดสอบสิทธิ์กับ Firebase ทั้งหมด

## การเผยแพร่และข้อมูลส่วนตัว

GitHub ใช้เก็บซอร์สโค้ด การนำโค้ดขึ้น GitHub ไม่ได้เผยแพร่เว็บหรือเปลี่ยน Firebase โดยอัตโนมัติ อ่าน `PILOT-RELEASE.md`, `PROGRESS.md` และเอกสารเฉพาะส่วนก่อนดูแลระบบจริง เครื่องมือใน `firebase/` บางรายการแก้ไขระบบออนไลน์ จึงไม่ควรรันโดยไม่ตรวจคำสั่งก่อน

ห้าม commit กุญแจบัญชีบริการ token ไฟล์ `.env` ข้อมูลผู้สมัคร ลายเซ็น หรือไฟล์สำรองฐานข้อมูล ค่า Firebase สำหรับเว็บเป็นข้อมูลการเชื่อมต่อสาธารณะ การป้องกันข้อมูลต้องอาศัย Rules และการตรวจสิทธิ์ของเซิร์ฟเวอร์
