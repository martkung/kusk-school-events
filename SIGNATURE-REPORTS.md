# Reports containing attendee signatures

The report table loads private signature thumbnails only for the currently rendered page, with at most three authorized callable requests at a time. It retains no signature image in browser storage or public links. Report metadata includes signature presence and the immutable SHA256, not its Storage path or applicant contact details. The existing signature view endpoint validates generation/digest and assigned role.

The พิมพ์ / บันทึก PDF พร้อมลายเซ็น action reloads current report data using the selected filters, includes all matching rows (up to 200 per document to bound mobile memory), and retrieves matching signatures with bounded concurrency. Missing signatures are explicitly labeled. Failed image loads, changed hashes, permission failures or changed filtered data block printing rather than produce a partial document. It rechecks report permission/data after image retrieval and again when the Print button is clicked, and waits for image decoding. Staff choose Print to PDF in their browser/device print dialog; CSV remains text-only.

The A4 portrait sheet shows school/event/date/place, filters and compilation time, applicant name and short reference, application/checkin status, and recorded signature/time. If the recorded signer name differs from the current applicant name, the evidence's original signer name is retained in the signature cell. Rows avoid page breaks and table headers repeat. A dedicated static print-output section avoids printing a clipped scrollable modal. Its DOM copy and the preview's private images are removed when closed or the account/page changes. Browser-native printing/saving is initiated only by the user; no report or copied signature is uploaded to a new destination.

Verification uses synthetic applicants/signature images and unit/DOM tests, including matching rows, missing signatures, auth failure, stale scope, changed data, print gating and DOM cleanup. No real attendee evidence was exported for QA. Local browser preview was attempted but the in-app browser could not connect to the local preview server; physical printer/PDF pagination is unverified in this environment.
